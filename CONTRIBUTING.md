# Contributing to Wails Plugin System Fork

## Plugin System Development

This fork focuses on developing a plugin system for Wails. When contributing to plugin-related features:

1. **Branch from `feature/plugin-system`**: All plugin work should be based on this branch
2. **Keep changes focused**: Only make changes related to the plugin system
3. **Maintain upstream compatibility**: Ensure your changes don't break existing Wails functionality
4. **Add tests**: All new plugin features must include comprehensive tests
5. **Document APIs**: Public plugin APIs must be well-documented

## General Wails Contributions

For general Wails contributions not related to the plugin system, please contribute directly to the upstream repository.

The current Contribution Guidelines can be found at: https://wails.io/community-guide
